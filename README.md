# aliucord-plugins

Plugins for [Aliucord](https://github.com/Aliucord/Aliucord) by sqyren.

## RingingPulse (unstable)

Adds green ripple rings around the caller's avatar on the incoming call screen, similar to the ringing effect on desktop Discord.

- Works on incoming calls
- Settings: ring color (hex code or preset colors), ring speed, and a reset button

### Install

1. Download [RingingPulse.zip](https://github.com/Sqyren/aliucord-plugins/raw/builds/RingingPulse.zip)
2. Move it to the `Aliucord/plugins` folder on your phone
3. Fully close and reopen Aliucord
4. Open RingingPulse's settings in the Plugins page to change color and speed
